# Haus of Micah — Monthly menu update instructions
Edit `monthly-menu.js` to change the featured plate each month. Update the name, `includes` array (one plain-language ingredient/dish per list item), photo and alt text, sample price, and pickup window labels/values. The list automatically appears on the homepage and payment preview. The name and sample price also populate the sample order and downloadable draft pickup card.

**Customer instructions:** check the included dishes; select quantity and pickup window; enter name and phone; proceed to the separate payment preview. No live payments or order collection are enabled.

**UX:** one task per step (Hick); large choices (Fitts); real HTML lists for scanability (Gestalt); familiar ordering (Jakob); content editable in one location (Tesler). Screen reader semantics and reduced-motion support remain in place.

**Production:** a verified, server-owned catalog and inventory is required before taking real charges. This client-side monthly menu is a *design preview source*, not transactional authority. All visible plate details and prices are samples pending client approval.
