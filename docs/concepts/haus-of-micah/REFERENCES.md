- https://www.concretecms.com/about/blog/web-design/7-fundamentals-of-web-design : seven web-design fundamentals.
- https://github.com/AlexJoom/laws-of-ux-examples : interactive before/after examples. Code MIT; illustrative assets have separate CC BY-NC-ND terms. Do not embed copied artwork in commercial materials.

- https://www.w3.org/WAI/WCAG22/quickref/ : normative WCAG requirements.
